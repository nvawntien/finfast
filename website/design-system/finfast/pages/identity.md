# Identity — BK-019 Phase 3

Extends [MASTER.md](../MASTER.md). Phase 1 restrictions describe the historical
foundation; Phase 3 enables only register/login, session and Customer guards.

## Visual and interaction decisions

- Keep existing navy/white palette, system fonts, spacing, focus and reduced-motion tokens.
- Desktop: navy introduction beside a white form card. Tablet: stacked sections.
  Mobile: omit decorative introduction; preserve every form action and simulation notice.
- Visible labels, required markers, password-manager autocomplete, paste allowed,
  keyboard-operated password visibility toggle. No invented password complexity policy.
- Focusable error summary links to invalid fields; inline errors use `aria-describedby`.
  Pending and success states are announced; duplicate submit is blocked while pending.
- Registration success explicitly asks for separate login. Backend role is authoritative;
  no role selector, financial data, or Admin screen.

## UI UX Pro Max application

Read the installed `.agents/skills/ui-ux-pro-max/SKILL.md` and master first.
Applied skill searches: `error summary validation` and `accessible authentication`
in the UX domain, and `form state` for React. Kept suggestions within approved
