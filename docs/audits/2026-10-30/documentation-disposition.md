## Safe retirement rule

An operative source can move to docs/legacy or be removed only after the responsible owner confirms that every still-operative requirement, stable identifier, exception and dependency has a clear successor; all code, contract and documentation links resolve; the successor is accepted; and no current process or tool consumes the old path. Incomplete implementation is never a retirement criterion.
